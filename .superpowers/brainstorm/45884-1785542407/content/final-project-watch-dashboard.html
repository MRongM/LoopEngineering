最终边界
  • 默认显示非终态与暂停 Run；--all 包含完整终态历史。
  • TTY 每秒刷新，最后一个活动 Run 结束后保留终态帧并退出。
  • 不会采用、恢复、批准、验证或完成 Run；单个损坏 Run 只形成脱敏警告。
  • 无 Rich/Textual/curses，也没有 run 下的别名。
