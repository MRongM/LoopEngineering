  • 天然支持重定向

限制

B · 实时 Watch（推荐）

ANSI 原地刷新，展示状态、验收、预算和最近事件；非 TTY 自动退化为快照。

优点

  • 立即获得过程感
  • 仍适合普通 Shell

限制

  • 只提供轻量交互

C · 全屏 TUI

键盘导航、分页、筛选和详情面板，适合长时间观察复杂 Run。

优点

  • 信息密度最高
  • 适合多仓库运行

限制

  • 实现与跨平台成本最高
  • 可能引入终端 UI 依赖

建议先交付 B，并让同一渲染器支持 A；全屏 TUI 留到真实使用证明需要后再做。
